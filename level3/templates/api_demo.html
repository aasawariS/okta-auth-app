What is a token-gated API?

      
    
        
  1. When you logged in, Auth0 issued an access token
    2. 
        
  2. That token lives in your server-side session (not in the browser)
    3. 
        
  3. When you click a button above, your browser calls our Flask server
    4. 
        
  4. Our server reads the access token from the session
    5. 
        
  5. It attaches it as "Authorization: Bearer <token>" to the Auth0 call
    6. 
        
  6. Auth0 validates the token and returns your user info
    7. 
        
  7. In a real app your own API would validate the token the same way
    8. 
        
  8. No valid token means no response — the API is protected
    9.
