How role-based access works
  1. At login, Auth0 issues an ID token with user claims
  2. The server reads the email from the session claims
  3. It compares the email against the ADMIN_EMAILS list in .env
  4. If it matches, the @admin_required decorator allows access
  5. In production: use Auth0 roles → add a custom claim to the token → check that claim server-side instead of a .env list
